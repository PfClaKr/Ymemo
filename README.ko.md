# Ymemo

[English](README.md) · **한국어**

책상에도 휴대폰에도 붙여 두는 메모. 내 기기들끼리 직접 동기화되고, 종단간 암호화되며,
**사이에 누구의 서버도 없고**, 가입할 계정도 없습니다.

![데스크톱의 Ymemo](docs/screenshots/desktop.png)

- **내 것** — 기기마다 완전한 사본이 있고, 네트워크를 꺼도 그대로 동작합니다.
- **중간에 아무도 없음** — 기기끼리 직접 이야기합니다. 해지할 것도, 갑자기 잠길 것도 없습니다.
- **종단간 암호화** — 기기를 떠나는 것은 전부 암호문입니다. 마스터 비밀번호는 아예 기기를 떠나지
  않습니다.
- **무엇도 사라지지 않음** — 두 기기에서 동시에 고쳐도 한쪽이 이기는 대신 하나의 메모로
  합쳐집니다.

![한 기기에서 친 메모가 다른 기기에 나타나는 모습](docs/screenshots/sync.gif)

## 받기

| | 내려받을 파일 | 참고 |
|---|---|---|
| **Windows** | `ymemo-<version>-setup-x86_64.exe` | 설치 프로그램. 트레이 앱과 방화벽 규칙을 함께 등록합니다. |
| **Debian / Ubuntu** | `ymemo_<version>_amd64.deb` | `sudo apt install ./ymemo_<version>_amd64.deb` |
| **Fedora** | `ymemo-<version>-*.x86_64.rpm` | `sudo dnf install ./ymemo-<version>-*.rpm` |
| **Android** | `ymemo-<version>-android-arm64-v8a.apk` | 대부분의 휴대폰이 `arm64-v8a`입니다. 스토어를 거치지 않으므로 설치 권한을 한 번 물어봅니다. |

전부 [릴리즈 페이지](https://github.com/PfClaKr/Ymemo/releases/latest)에 있습니다. 따로 설치할
것은 없습니다 — 동기화 데몬은 안에 들어 있습니다.

앱은 하루에 한 번쯤 새 버전이 있는지 확인하고, 지금 쓰는 기기에 맞는 파일 하나만 알려 줍니다.
스스로 내려받거나 설치하는 일은 절대 없고, 이 확인은 꺼 둘 수 있습니다. 아래
[기기 밖으로 나가는 것](#기기-밖으로-나가는-것)을 보세요.

## 처음 시작할 때

처음 실행하면 앱이 딱 하나를 묻습니다. 이 답이 중요합니다:

<img src="docs/screenshots/setup.png" alt="첫 실행 화면" width="330">

- **새로 시작하기** — 첫 기기입니다. 마스터 비밀번호를 정하고 바로 쓰기 시작하세요.
- **다른 기기와 연결하기** — 이미 다른 곳에서 Ymemo를 쓰고 있고, 그 메모를 그대로 가져옵니다.
  여기서 '새로 시작하기'를 먼저 누르면 새 기기가 자기만의 열쇠를 갖게 되어 두 기기는 영영
  합쳐지지 않습니다.

보관함을 만들고 나면 **복구 코드**가 한 번 나옵니다. 마스터 비밀번호와 함께, 이 세상에서 당신의
메모를 열 수 있는 단 두 가지 중 하나입니다. 재설정 링크 같은 것은 없습니다 — 보내 줄 사람이
없으니까요.

제목을 눌러 보관함에 이름을 붙이세요. 이름은 메모와 함께 다니므로, 연결한 모든 기기가 같은
이름을 보여줍니다.

## 무엇을 할 수 있나

- **메모답게 구는 메모.** 치는 대로 저장되는 테두리 없는 쪽지입니다. 제목 줄을 두 번 누르면
  접히고, 끌면 화면 가장자리와 다른 쪽지에 착 붙습니다. 작업 표시줄에는 남지 않고 트레이로 다시
  불러옵니다. 쪽지마다 **색상**과 **투명도**를 따로 가지며, **압정**은 하나를 모든 창 위로
  올려 둡니다.
- **원할 때만 켜지는 마크다운.** 보통 줄은 친 그대로입니다 — 장보기 목록의 ` **별표** `는
  그냥 별표입니다. 빈 ```` ``` ```` 로 감싸면 서식이 살아나고, ```` ```rust ```` 로 감싸면 색이 붙은
  코드 블럭이 됩니다.
- **종이 위의 사진.** 메모에 끌어다 놓고 옮기거나 크기를 바꾸세요. 글 아래 자기 자리를 주면
  글을 가리지 않습니다. 크기는 함께 다니므로, 휴대폰에서 줄인 사진은 27인치 모니터에서도 글에
  대해 같은 크기로 보입니다.
- **폴더.** 중첩할 수 있고, 끌어다 옮길 수 있고, 자기 색을 가집니다. 폴더를 지워도 안에 있던
  것은 한 단계 위로 올라올 뿐 사라지지 않습니다.
- **기억되는 순서.** 목록의 두 행 **사이**로 끌면 그 자리에 놓이고, 폴더 **위**에 놓으면 그
  폴더로 들어갑니다. 순서는 폴더마다 따로이고 동기화됩니다.
- **다시 찾기.** 목록 위의 찾기 칸은 폴더를 가리지 않고 한 번에 전부 뒤지고, 제목뿐 아니라
  적어 둔 내용까지 봅니다.
- **되돌아갈 길.** 지우면 "정말요?"를 묻는 대신 몇 초 동안 되돌릴 기회를 줍니다. 그리고 메모와
  폴더의 지나간 모든 버전이 남습니다 — 그때 뭐라고 적혀 있었는지, 언제, 어느 기기가 바꿨는지
  — 어느 것으로든 되돌릴 수 있습니다.
- **휴대폰에서도.** 같은 메모, 같은 폴더, 같은 사진, 같은 변경 기록. 여기에 홈 화면 위젯 셋과
  단축키 둘이 더 있습니다. 앱이 잠기는 순간 위젯은 비워집니다.
- **잠금.** 마스터 비밀번호, 즉시 잠그기, 자리를 비우면 자동 잠금, 그리고 원하면 정해 둔 일수
  동안 잠금 해제 유지. 안드로이드에서는 **지문**으로 다시 열 수도 있습니다.
- **기기 연결.** 상대 기기의 QR을 찍거나 페어링 코드를 입력하면, 양쪽 화면에 같은 여덟 글자가
  떠서 맞는 기기인지 확인할 수 있습니다. 세 번째 기기부터는 각 기기가 서로를 소개하므로 모두가
  직접 주고받습니다. 기기 해제는 보관함에 기록되므로 다른 기기들도 함께 그 기기를 놓고, 다시
  연결하기 전까지는 그대로입니다. 고친 내용은 20초쯤이면 다른 기기에 닿고, 설정 > 고급에서
  배터리와 맞바꿔 더 빠르게 할 수 있습니다.
- **한국어와 영어.** 시스템 언어를 따라가고 설정에서 바꿀 수 있습니다.

## 기기 밖으로 나가는 것

메모는 암호문으로만, 연결해 둔 기기에만, 그 기기들끼리 맺은 연결로만 나갑니다.

앱이 남의 서버에 보내는 요청은 **딱 하나**입니다. 새 릴리즈가 있는지 GitHub에 하루 한 번 묻는
것. 보관함의 내용도, 기기 식별자도, 당신을 알아볼 수 있는 무엇도 담기지 않습니다 — 다만 IP
주소는 GitHub에 닿으므로, 설정에서 끌 수 있습니다.

두 기기가 서로 직접 닿지 못하면 동기화가 Syncthing의 공개 릴레이를 거칠 수 있습니다. 릴레이는
암호화된 바이트를 넘길 뿐 읽지 못합니다.

암호화가 무엇을 지키고 무엇을 지키지 않는지 — 각 기기의 로컬 캐시는 **평문**이라 잠금이 풀린
상태의 기기를 남이 읽을 수 있으면 숨겨지는 것이 없다는 점을 포함해 —
[SECURITY.md](SECURITY.md)에 적어 두었습니다.

## 개발자용

Rust 코어(`ymemo-core`) 위에 얇은 UI 둘 — 데스크톱은 Slint, 안드로이드는 Flutter. 하나의 Cargo
워크스페이스에 네 개의 크레이트가 있습니다.

**필요한 것**

- Rust **1.87 이상**
- 리눅스: `libfontconfig1-dev`(Slint가 fontconfig에 링크합니다)와 한글 표시를 위한
  `fonts-noto-cjk`
- 안드로이드만: Flutter와 Android SDK/NDK — [apps/mobile/README.md](apps/mobile/README.md)
  참고

**빌드와 실행**

```bash
cargo test --workspace
cargo run -p ymemo-desktop
```

앱 데이터는 플랫폼 데이터 디렉터리(리눅스 `~/.local/share/ymemo`, 윈도우
`%APPDATA%\ymemo\Ymemo\data`)에 있고, 그중 암호화된 `vault/`만 동기화됩니다. 다른 곳에 두려면
`YMEMO_DATA_DIR`를 지정하세요 — 실제로 쓰는 보관함을 건드리지 않고 빌드를 시험할 때 이렇게
합니다. `ymemo --purge`는 이 기기의 사본만 지우고 다른 기기에는 손대지 않습니다.

패키징 — `.deb`, `.rpm`, Inno Setup 설치 파일, ABI별 APK — 은 `packaging/` 아래에 스크립트로
있고 `v*` 태그에서 [.github/workflows/release.yml](.github/workflows/release.yml)이 만듭니다.
